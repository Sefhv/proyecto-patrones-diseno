🍕 Sistema de Pedidos de Comida

Demostración de Patrones de Diseño en Node.js

📋 Introducción

Bienvenido al sistema de gestión de pedidos de comida a domicilio. Esta aplicación demuestra la implementación práctica de tres patrones de diseño fundamentales: Singleton, Builder y Observer.

El sistema permite crear pedidos de comida de forma estructurada y escalable, con notificaciones automáticas y configuración centralizada.

🎯 Patrones de Diseño Implementados

🔒 Singleton

Propósito: Garantizar una única instancia de configuración en toda la aplicación.

Ubicación: public/config/AppConfig.js

Ventaja: Evita duplicación y mantiene consistencia en la configuración global.

🏗️ Builder

Propósito: Construir objetos complejos paso a paso de forma legible.

Ubicación: public/order/OrderBuilder.js

Ventaja: Facilita la creación de pedidos con múltiples parámetros opcionales.

👁️ Observer

Propósito: Sistema de notificaciones desacoplado para eventos.

Ubicación: public/notifications/

Ventaja: Permite agregar nuevos observadores sin modificar código existente.

🚀 Cómo Usar los Servicios

1. Ver la Configuración (Singleton)

GET /api/config

Obtiene la configuración única de la aplicación. Demuestra el patrón Singleton.

Ejemplo de uso con cURL:

curl http://localhost:8080/api/config
Respuesta esperada: 
{
  "message": "Esta es la configuración única de la aplicación (Singleton)",
  "config": {
    "appName": "Sistema de Pedidos de Comida",
    "version": "1.0.0",
    "defaultCurrency": "EUR",
    "supportEmail": "soporte@mi-restaurante.com"
  }
}

2. Crear un Pedido de Demostración

POST /api/orders/create-demo

Crea un pedido de ejemplo predefinido. Demuestra los patrones Builder y Observer.

Ejemplo de uso con cURL:

curl -X POST http://localhost:8080/api/orders/create-demo \ -H "Content-Type: application/json"
Respuesta esperada: 
{

  "message": "Pedido creado exitosamente",

3. Crear un Pedido Personalizado

POST /api/orders

Crea un pedido personalizado con tus propios datos. Demuestra el patrón Builder.

Estructura del cuerpo de la petición:

{ "customerName": "María López", "address": "Av. Principal 45, Ciudad Y", "items": [ { "name": "Hamburguesa Doble", "quantity": 1, "price": 10 }, { "name": "Papas Fritas", "quantity": 2, "price": 2.5 } ], "deliveryFee": 2, "paymentMethod": "CASH" }

Ejemplo de uso con cURL:

curl -X POST http://localhost:8080/api/orders \ -H "Content-Type: application/json" \ -d '{ "customerName": "María López", "address": "Av. Principal 45", "items": [ {"name": "Hamburguesa", "quantity": 2, "price": 10}, {"name": "Patatas", "quantity": 1, "price": 2.5} ], "deliveryFee": 2, "paymentMethod": "CASH" }'

    "deliveryFee": 2,
